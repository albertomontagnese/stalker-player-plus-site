Setup guide

Add an Xtream Codes provider

Xtream setup uses three values from your provider: a server URL, username, and password. You do not need to construct an M3U link yourself.

Before you begin: SuperPlayer is an independent media player and provides no channels or subscriptions. Use only services and media you are authorized to access.

What you need

  • The server or portal URL, including its port when supplied.
  • Your Xtream username.
  • Your Xtream password.

Setup steps

  1. Open SuperPlayer and choose Add Provider.
  2. Select Xtream Codes.
  3. Enter the server URL. For example, https://example.com:8080.
  4. Enter the username and password exactly, without extra spaces.
  5. Save and let SuperPlayer test the account and download the channel list.

If the login fails

Invalid credentials

Re-enter all three values and check capitalization. Test the same credentials with your provider's web endpoint or another authorized player to confirm that the account is active.

Server unavailable

A timeout, DNS error, certificate problem, or blocked server usually points to the provider or network. Try the same device on another network, then ask the provider whether the hostname and port have changed.

Login works but streams fail

Test several channels. Individual offline streams are controlled by the provider. If all playback fails, send support the exact error and whether the problem happens on Wi-Fi and another network.

Need a hand? Email support@infoalerts.online with your device, app version, server domain, and exact error. Do not send your password.
